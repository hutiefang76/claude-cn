# claude-cn · Claude 中文版

中文 AI 工作台。采用米白色桌面、左侧导航、福利大厅、橙色操作按钮、会员成长条及底部模型菜单，支持桌面和手机布局。


## 启动

需要 Node.js 20.11+，无需安装任何 npm 依赖。

```bash
git clone https://github.com/hutiefang76/claude-cn.git
cd claude-cn
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。自定义端口：`PORT=8080 npm run dev`。项目使用 ES Modules，请通过 HTTP 服务访问，不要直接双击 HTML 文件。

```bash
npm test       # 状态规则测试
npm run build  # 生成 dist/ 静态文件
npm run check  # 语法检查、测试、构建
```

将 `dist/` 内容放入 Nginx、GitHub Pages、Cloudflare Pages 或其他静态托管即可。资源使用相对路径，也支持部署到 `/claude-cn/` 子目录。GitHub Pages 若使用 main 分支根目录发布，可直接使用仓库根目录，不需要构建。

## 工作区 2.0

首页进入任务工作区。点击「做一个简洁的登录页」即可开始：拆解需求 → 生成文件 → 编写交互 → 检查文件 → 执行报告 → 交付。

- 每一步有固定计费、日志和检查点；余额不足自动暂停，补充额度后从同一步继续，不重复扣费。
- 登录页、待办清单、数据看板和产品展示页由浏览器内置生成器产生 HTML / CSS / JavaScript。支持从需求识别页面类型、紫/绿/橙配色、深色主题和引号内标题。
- 文件树、源码编辑、修改对比、执行终端、隔离 iframe 预览均使用同一份文件内容。源码编辑自动保存。
- ZIP 导出包含当前编辑后的所有文件，可解压独立运行；Token 流水可下载为 CSV。
- 钱包、订单、Token 流水、会员、导出通行证和加速权益相互关联。订单防止重复支付。
- A7 自动续费可通过会员中心三步关闭，保留本期权益。钱包初始余额 ¥500，账户状态保存在浏览器，不发起外部支付请求。
- 客服读取当前任务、消耗、余额及权益；可提交并保存工单。
- 刷新保留任务、订单、文件和检查点；运行中的任务恢复后等待手动继续。

任务生成使用本地规则与模板，源码入口为 `src/engine.js`；后续可替换为模型服务。当前覆盖上述四类页面，任意软件开发需求需要扩展生成器或接入后端。

- 免费盲盒、每日次数限制、广告增加次数。
- 新人礼包、兑换码 `HELLOCLAUDE`、余额管理、好友助力及邀请码复制。
- 会员等级选择、免费体验 A7、模型菜单、加速倍率、插件偏好。
- 代码助手、智能问答、数据分析和绘图提示词工作区。

## 使用规则

盲盒奖励概率：20 Token 50%；60 Token 30%；120 Token 15%；500 Token 4.5%；50,000 Token 0.5%。每日 3 次基础机会，每完成 3 条广告增加 1 次。

连续签到按浏览器本地日期计算，7 天一轮奖励为 20、40、60、80、100、120、120 Token。数据通过 localStorage 保存在当前浏览器中。

## 项目结构

```text
index.html          页面入口
favicon.svg         本地矢量图标
src/app.js          页面组件、事件与交互
src/styles.css      响应式样式
src/state.js        状态恢复、签到和奖励规则
src/engine.js       任务执行、交易与客服逻辑
src/workbench.js    工作区、账单和订阅页面
src/workbench.css   工作区响应式布局
src/archive.js      ZIP 文件打包
scripts/serve.mjs   零依赖开发服务器
scripts/build.mjs   静态构建
tests/              状态与边界测试
```

## API 扩展

在 `src/app.js` 的 `submit()` 中扩展消息处理逻辑，调用你自己的后端 API。API Key 应仅保存在服务端环境变量中；前端不要保存供应商密钥。生产环境的身份认证、余额、支付、限额和奖励校验应在服务端实现。

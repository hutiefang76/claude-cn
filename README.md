# claude-cn · Claude 中文版

基于趣味参考图制作的中文 AI 工作台界面。保留米白色桌面、左侧导航、福利大厅、橙色操作按钮、会员成长条及底部模型菜单，支持桌面和手机布局。

**这是非官方前端交互演示，与 Anthropic 无关联。** 不提供真实 Claude 模型、充值、贷款、投资、广告服务或返利。截图中的模型名称和商业规则仅作为视觉创意呈现。

## 启动

需要 Node.js 20.11+，无需安装任何 npm 依赖。

```bash
git clone https://github.com/hutiefang76/claude-cn.git
cd claude-cn
npm run dev
```

打开 http://localhost:3000。自定义端口：`PORT=8080 npm run dev`。项目使用 ES Modules，请通过 HTTP 服务访问，不要直接双击 HTML 文件。

```bash
npm test       # 状态规则测试
npm run build  # 生成 dist/ 静态文件
npm run check  # 语法检查、测试、构建
```

将 `dist/` 内容放入 Nginx、GitHub Pages、Cloudflare Pages 或其他静态托管即可。资源使用相对路径，也支持部署到 `/claude-cn/` 子目录。GitHub Pages 若使用 main 分支根目录发布，可直接使用仓库根目录，不需要构建。

## 功能边界

对话回复是本地预设文案；联网搜索、深度思考、插件、定时任务和多 Agent 团队尚未连接后端。附件仅展示文件名，不上传或解析。会员及加速不影响真实模型能力。金融收益、榜单、PR 和日程为固定样例。所有余额及奖励均为本地演示数据，可由用户修改，不可用于生产计费。

盲盒奖励概率：20 Token 50%；60 Token 30%；120 Token 15%；500 Token 4.5%；50,000 Token 0.5%。每日 3 次基础机会，每完成 3 条广告增加 1 次。页面上的 `0.99$ 抽` 是参考图视觉文案，实际操作完全免费。

连续签到按浏览器本地日期计算，7 天一轮奖励为 20、40、60、80、100、120、120 Token。浏览器数据只保存在当前设备，没有跨设备账户同步。

## 项目结构

```text
index.html          页面入口
favicon.svg         本地矢量图标
src/app.js          页面组件、事件与交互
src/styles.css      响应式样式
src/state.js        状态恢复、签到和奖励规则
scripts/serve.mjs   零依赖开发服务器
scripts/build.mjs   静态构建
tests/              状态与边界测试
```

## 后续接入真实 AI

在 `src/app.js` 的 `submit()` 中替换本地演示回复，调用你自己的后端 API。API Key 应仅保存在服务端环境变量中；前端不要保存供应商密钥。生产环境的身份认证、余额、支付、限额和奖励校验应在服务端实现。此仓库未包含这些后端服务。
